# 在本机训练主动抱抓

训练直接运行在你的电脑上：`/home/zhe/GPTControl`、conda 环境 `env_isaaclab`、本机 NVIDIA GPU，无需云训练服务。`--headless` 仅表示不打开渲染窗口，不表示远程训练。

## 启动与续训

```bash
cd /home/zhe/GPTControl
./train_hug.sh
# 显存不足时减少环境数，更新次数可自行设置。
HUG_ENVS=128 HUG_ITERATIONS=3000 ./train_hug.sh
# 同任务续训，恢复网络与优化器。
./train_hug.sh --resume logs/rl_hug/某次训练/model_500.pt
# 从新初始化的神经网络开始。
./train_hug.sh --scratch
```

默认 256 个并行环境、1500 次更新，在终端显示训练过程；Ctrl+C 停止，每 50 次更新保存模型。`logs/rl_hug/日期时间/` 保存权重、TensorBoard 日志、源码和配置快照。`ISAACLAB_PYTHON` 可覆盖解释器路径。

默认迁移 v2 的全身动作网络，价值网络与优化器重新初始化以适应新奖励。`--scratch` 重新初始化全部网络。两种方式均保留分层控制器提供的基础目标，由 PPO 根据观测学习 23 个关节的修正，包括双臂、腰和腿；不是播放固定动画，也不是完全无先验的端到端策略。

严格抱抓采用有限时长任务，终点不补算未来价值。固定学习率 `3e-5`、折扣因子 `0.999`、熵系数 `0`；迁移时动作噪声标准差设为 `0.04`，减少探索直接破坏抱持的问题。续训恢复检查点中的噪声参数。

## 失败与成功

新配置 `env_configs/rl_hug.py` 默认每回合 8 秒：

- 物体**中心**离地高度低于 0.50 m，判为离开抱抓区域，立即失败；不必等到完全落地。
- 物体飞过身体后方 0.6 m 或水平距离超出 2 m，视为漏接失败。
- 跌倒立即失败。失败只重置当前并行环境，0.5 秒后再次投放另一种物体。“重新抓取”是重新接抛掷物体，不是从地上捡起同一个物体。
- 成功必须在回合结束时仍由躯干、左臂、右臂共同接触，并连续抱稳至少 2 秒。短暂接住后掉物仍算失败，超时未抱稳也失败。

在新配置中修改 `drop_height`、`required_hold_seconds`、`episode_seconds`。旧配置保留旧任务，新任务必须使用 `rl_hug.py`。

## 奖励

实现集中在带中文注释的 `controllers/hug_reward.py`，不再叠加旧站立奖励与短暂接住的大奖。

| 行为 | 奖励/惩罚 |
| --- | --- |
| 靠近、单臂/双臂承接 | 小额辅助奖励，投放后按 2 秒时间常数衰减 |
| 双臂与胸部共同接触且低相对速度 | 最高 12/秒 |
| 连续抱稳 | 随连续时长增加，最高 30/秒 |
| 抱持中稳定支撑 | 最高 1/秒，空手站立不获此奖励 |
| 承接时物体下滑 | 按下滑速度惩罚 |
| 终点仍连续抱稳 ≥2 秒 | +100 |
| 掉物/漏接 | -60，立即结束回合 |
| 跌倒 | -80，立即结束回合 |
| 超时未抱稳 | -30 |
| 等待、过大或抖动动作 | 时间成本与动作正则惩罚 |

掉物/跌倒步屏蔽所有正奖励，两种失败同时发生则惩罚相加。每秒奖励乘控制周期，事件奖励直接计入。小额辅助奖励引导“接近→包围→抱持”，主要回报来自持续抱稳。

## 观察与评估

```bash
conda activate env_isaaclab
tensorboard --logdir logs/rl_hug --host 127.0.0.1 --port 6006

python run.py --mode eval --config env_configs/rl_hug.py --num_envs 96 \
  --eval_episodes 96 --eval_seed 2041 --checkpoint 模型路径.pt \
  --eval_output logs/rl_hug/evaluation.json --headless

python run.py --mode play --config env_configs/rl_hug.py --num_envs 1 \
  --steps 0 --checkpoint 模型路径.pt
```

浏览器打开 `http://127.0.0.1:6006`。观察 `Episode/catch_success`（严格终点成功）、`Episode/drop`、`Episode/fall`。训练曲线含探索噪声，最终看关闭探索噪声后的独立评估。JSON 分别报告掉物与跌倒，新成功率不能与旧版短时接住率直接比较。

也可运行 `./play_hug.sh 模型路径.pt` 打开单环境回放；默认使用本次打包的 v3 模型。旧 `play_stable.sh` 仍为旧版任务。

## 本次本地试训（2026-09-11）

在本机 RTX 5060 Ti 完成正式试训 300 次更新，256 个并行环境、2,457,600 个仿真步，日志为 `logs/rl_hug/local_v3_run3/`。前两次调试运行分别完成 163 和 29 次更新后停止；其日志保留，但不作为最终训练结果。

在 seed=2040 的 48 回合验证集上比较每 50 次保存的检查点及最终检查点：选择 `model_200.pt`，终点严格成功 22 次、掉物 9 次、跌倒 0 次、超时未抱稳 17 次。旧 v2 在相同新规则下严格成功 23 次，因此本轮没有在该验证集上证明优于旧策略。最后一次保存的模型成功数仅 8 次，不采用最后一次权重作为最佳模型。

候选模型打包在 `trained_models/strict_hug_v3/model_best.pt`；`model_selection.json` 保存全部比较结果与模型校验值。可以从它续训：

```bash
HUG_ITERATIONS=1500 ./train_hug.sh --resume trained_models/strict_hug_v3/model_best.pt
```

22 项单元测试通过；实际 PhysX 注入掉物检查通过，覆盖掉物负奖励、失败覆盖过去成功、局部自动复位和重新投放。此模型是新奖励任务的试训候选，不代表已经解决持续抱持问题。

模型选择完成后，独立 seed=2041、96 回合、每回合 8 秒、三类物体各 32 次，关闭探索噪声，结果如下：

| 新任务判据 | 旧 v2 | 新候选 v3 |
| --- | ---: | ---: |
| 回合结束仍连续抱稳 ≥2 秒 | 36/96（37.5%） | 47/96（49.0%） |
| 掉物/漏接终止 | 16 | 13 |
| 跌倒 | 0 | 0 |
| 超时未达到抱稳要求 | 44 | 36 |

这组独立测试有改善，但验证集未改善，且样本有限，不能据此保证其他来物同样提升。仍有较多超时未抱稳，需要继续训练与验证。完整逐回合报告在 `trained_models/strict_hug_v3/holdout.json` 和 `old_v2_holdout.json`。打包模型已通过无界面加载回放检查。
